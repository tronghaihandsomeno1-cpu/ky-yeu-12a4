# Website kỷ yếu 12A4 — 2026

## Cách đăng lên GitHub Pages
1. Mở repository `ky-yeu-12a4` trên GitHub.
2. Chọn **Add file → Upload files**.
3. Giải nén ZIP này trên máy tính, rồi kéo 3 file `index.html`, `style.css`, `script.js` và `README.md` vào trang Upload files.
4. Chọn **Commit changes**.
5. Mở **Settings → Pages**.
6. Ở **Build and deployment**, chọn **Deploy from a branch**.
7. Branch chọn `main`, folder chọn `/ (root)`, nhấn **Save**.
8. Chờ GitHub Pages xuất bản, đường dẫn dự kiến:
   https://tronghaihandsomeno1-cpu.github.io/ky-yeu-12a4/

## Lưu ý quan trọng về dữ liệu
Đây là bản website tĩnh chạy trên GitHub Pages. RSVP, lời chúc và bảng quản trị dùng `localStorage`, nghĩa là dữ liệu chỉ nằm trong trình duyệt/thiết bị nơi người dùng gửi. Các khách truy cập khác không tự động nhìn thấy dữ liệu đó và ban tổ chức không nhận được thông báo. Muốn có dữ liệu chung cho cả lớp cần kết nối thêm dịch vụ cơ sở dữ liệu/backend.

Ảnh trong bản mẫu là ảnh minh họa từ Unsplash. Có thể thay URL ảnh trong `index.html` bằng ảnh thật của lớp.
